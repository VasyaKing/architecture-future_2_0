| **Домен**                                         | **Почему выделен в отдельный домен**                                                   | **Преимущества для бизнеса**                                                                                                           |
|---------------------------------------------------|----------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------|
| **Медицинский домен**                             | Собственная предметная область, чувствительные медданные, уникальные процессы лечения. | Комплаенс, независимое развитие клиник, быстрое внедрение медицинских функций.                                                         |
| **Финтех-домен**                                  | Отдельная логика финансовых продуктов и регуляторные требования.                       | Быстрый вывод финтех-продуктов, высокая отказоустойчивость, нет нагрузки на DWH.                                                       |
| **Домен ИИ-сервисов**                             | Отдельный ML-жизненный цикл (обучение, эксперименты, inference).                       | Быстрое развитие моделей, минимальное влияние на медицину, аналитика качества моделей.                                                 |
| **Партнёрский домен (фарма / электроника)**       | Каждый партнёр имеет уникальные процессы и форматы данных.                             | Лёгкое подключение новых партнёров без изменения DWH, масштабирование экосистемы.                                                      |
| **Платформа данных (Data Platform)**              | Централизованная аналитическая инфраструктура, но без операционной логики доменов.     | Быстрая отчётность, витрины по каждому направлению, отказ от устаревшего DWH.                                                          |
| **Корпоративный домен (HR, инвентарь)**           | Внутренние процессы HR, не связанные с медициной или финтехом.                         | Независимое развитие внутренних систем и отдельная аналитика.                                                                          |
| **Домен интеграции**                              | Общий транспорт данных между доменами (шина событий, API gateway).                     | Минимизация связности, независимость доменов, масштабируемые интеграции.                                                               |
| **Портал данных и BI (витрина самообслуживания)** | Пользовательский интерфейс для доступа к данным: портал, BI, отчёты, поиск данных.     | Самостоятельная аналитика без участия ИТ, сокращение времени принятия решений, доступ к витринам без нагрузки на операционные системы. |
