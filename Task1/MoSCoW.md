| Приоритет  | Проблема                           | Почему важно               | Какие сценарии страдают                   |
|------------|------------------------------------|----------------------------|-------------------------------------------|
| **Must**   | Монолитный DWH                     | Блокирует развитие доменов | Скорость аналитики, независимость доменов |
| **Must**   | SQL Server 2008 не масштабируется  | Отчёты часами              | Управленческие решения, финтех-отчётность |
| **Must**   | Медкарты в аналитике               | Риски комплаенса           | Безопасность, регулирование               |
| **Must**   | BI зависит от DWH                  | BI тормозит вместе с DWH   | BI-отчёты, финансовые отчёты              |
| **Must**   | Нет управления доступом            | Риск утечек                | Доступ к мед/фин данным                   |
| **Should** | Устаревшая шина                    | Тяжёлая интеграция         | Подключение новых направлений             |
| **Should** | Медленное создание отчётов         | Требует программистов      | Гибкость BI                               |
| **Could**  | Дублирование данных                | Рост затрат                | Операционные расходы                      |
| **Could**  | Ограничения ИИ-интеграции          | Замедляет развитие         | Масштабирование ИИ                        |
| **Won’t**  | Низкоприоритетные улучшения клиник | Не влияет на стратегию     | Операционная работа                       |
